# Learning Graph for Mountainash Rules Babel

This section contains the learning graph for the mountainash-rules-babel package — a format translation engine for decision tables and business rules.

The graph maps 70 concepts covering the plugin architecture, importers (CSV), exporters (DMN 1.3 XML, CSV), FEEL expression mapping, validators, decomposers, CLI, and error handling.
